# P4.4 — Pool de imágenes curado + picker no-repetición

> Sub-plan de [P4-composable-blocks.md](./P4-composable-blocks.md) (entregable 3 / fase 3). Leé el padre §Entregable 3.

## Objetivo
Imágenes stock free-use, variadas y temáticas por rol, sin repetición dentro de una misma página.

## Contexto necesario
- Padre P4 §Entregable 3. P4.1 (paquete worker-assembly).

## Entregables
1. `src/blocks/images.ts`: 12-15 URLs free-use **verificadas 200 OK** en categorías: `courthouse, columns, library, office_interior, desk_detail, city_misiones, skyline, handshake, scales, books`.
2. Picker: asigna por rol de bloque (hero≠about≠cta), **garantiza no-repetición** en una página, agrega params de tamaño/calidad + `alt` temático.

## Gates
- Build + lint OK.
- `vitest run`: test no-repetición (pedir N imágenes para N bloques → todas distintas), test de `alt` no vacío. Verificación 200 OK de URLs puede ser script aparte (no test de red en CI).

## Criterio de parada
Picker entrega imágenes distintas por página, alts temáticos, URLs validadas una vez.

## Bitácora
- 2026-06-24 — Implementado `packages/worker-assembly/src/blocks/images.ts`.
  - **Pool:** 15 URLs free-use (Unsplash License, sin atribución) cubriendo las 10 categorías (`courthouse, columns, library, office_interior, desk_detail, city_misiones, skyline, handshake, scales, books`). Las 15 ids verificadas **200 OK** vía `curl` una sola vez (1 candidata descartada por 404). `POOL_IDS` exportado para un re-check fuera de banda; no hay test de red en CI.
  - **Picker:** `pickImages(roles, width?)` asigna una imagen por rol de bloque con preferencia de categoría por rol (`hero`/`about`/`cta`/`areas`/`contact`), **garantiza no-repetición** por página (fallback a cualquier imagen libre), agrega `?w=&q=70&auto=format&fit=crop` y `alt` temático en español. Determinista. Lanza error si se piden más roles que imágenes.
  - **Tests (`test/images.test.ts`, vitest):** no-repetición (N bloques → N urls distintas y pool completo), `alt` no vacío, categorías hero/about/cta distintas, params de width/quality, guard de exhaustion. 6 verdes.
  - **Gates:** `build` ✅ · `lint` (tsc --noEmit) ✅ · `vitest run` 19/19 ✅. Commit convencional local, sin push (instrucción del usuario).
  - Nota: el plan pide `src/blocks/images.ts` (creado); el `src/sections/images.ts` preexistente es un helper distinto (2 backgrounds para el render) y se deja intacto.
